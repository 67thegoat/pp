================================================================================
HOW TO CREATE NEW PARENT AND CHILD ITEMS IN INFO.HTML
================================================================================

OVERVIEW:
This guide explains how to add custom parent-child navigation categories and 
their corresponding documentation content to the ABOUT JCB PARTS page.

================================================================================
STEP 1: ADD PARENT-CHILD IN THE SIDEBAR
================================================================================

Location: info.html - Inside <aside class="sidebar"> section

Copy and paste this template:

<div class="nav-group">
  <div class="nav-item parent-item" onclick="toggleChildren(this)">
    EMOJI YOUR PARENT NAME
    <span class="toggle-icon">▶</span>
  </div>
  <div class="nav-children" style="display:none;">
    <div class="nav-item child-item" onclick="showContent('unique-id-1')">Your Child Item 1</div>
    <div class="nav-item child-item" onclick="showContent('unique-id-2')">Your Child Item 2</div>
    <div class="nav-item child-item" onclick="showContent('unique-id-3')">Your Child Item 3</div>
  </div>
</div>

CUSTOMIZATION NOTES:
- Replace "EMOJI" with any emoji you want (e.g., 🔧, 🔩, ⚙️, 📋, etc.)
- Replace "YOUR PARENT NAME" with your category name
- Replace "unique-id-1", "unique-id-2", etc. with descriptive IDs (no spaces, use hyphens)
- Change "Your Child Item 1", "Your Child Item 2" to your actual child names
- You can add as many children as needed

EXAMPLE:
<div class="nav-group">
  <div class="nav-item parent-item" onclick="toggleChildren(this)">
    🚜 Transmission System
    <span class="toggle-icon">▶</span>
  </div>
  <div class="nav-children" style="display:none;">
    <div class="nav-item child-item" onclick="showContent('trans-overview')">System Overview</div>
    <div class="nav-item child-item" onclick="showContent('trans-maintenance')">Maintenance Guide</div>
    <div class="nav-item child-item" onclick="showContent('trans-troubleshoot')">Troubleshooting</div>
  </div>
</div>

================================================================================
STEP 2: ADD CONTENT SECTIONS
================================================================================

Location: info.html - Inside <section class="main-content"> section

For each child item you created in Step 1, add a corresponding content section 
with the SAME ID:

<div id="unique-id-1" class="content-section">
  <h2>Your Child Item 1 Title</h2>
  <p>Your documentation content goes here...</p>
  <div id="your-doc-container-1" class="document-card-wrapper"></div>
</div>

IMPORTANT: The id attribute in the content-section MUST match the onclick 
value in the sidebar child-item.

EXAMPLE FOR TRANSMISSION SYSTEM:
<div id="trans-overview" class="content-section">
  <h2>Transmission System Overview</h2>
  <p>Information about JCB transmission systems, including how they work 
  and key maintenance points.</p>
  <div id="trans-overview-doc" class="document-card-wrapper"></div>
</div>

<div id="trans-maintenance" class="content-section">
  <h2>Transmission Maintenance Guide</h2>
  <p>Step-by-step maintenance procedures for transmission systems.</p>
  <div id="trans-maintenance-doc" class="document-card-wrapper"></div>
</div>

<div id="trans-troubleshoot" class="content-section">
  <h2>Transmission Troubleshooting</h2>
  <p>Common issues and solutions for transmission problems.</p>
</div>

================================================================================
STEP 3 (OPTIONAL): ADD CUSTOM DOCUMENTATION FILES
================================================================================

If you want to load content from external JavaScript files:

1. Create a new .js file (e.g., transmission.js) in your workspace folder

2. Add content to the file:

document.getElementById('trans-overview-doc').innerHTML = `
  <div class="document-card">
    <p class="document-topic">TRANSMISSION SYSTEMS</p>
    <h3>System Overview</h3>
    <p class="document-summary">
      This guide covers the basics of JCB transmission systems, 
      including hydraulic and mechanical components.
    </p>
    <ul>
      <li>Main components</li>
      <li>Operating principles</li>
      <li>Safety considerations</li>
    </ul>
  </div>
`;

document.getElementById('trans-maintenance-doc').innerHTML = `
  <div class="document-card">
    <p class="document-topic">MAINTENANCE</p>
    <h3>Maintenance Procedures</h3>
    <p class="document-summary">Follow these steps for regular maintenance.</p>
  </div>
`;

3. Link the file in info.html (add near the other script tags):

<script src="transmission.js"></script>

================================================================================
COMPLETE WORKING EXAMPLE
================================================================================

IN THE SIDEBAR (inside <aside class="sidebar">):
---
<div class="nav-group">

document.getElementById('brake-parts-doc').innerHTML = `
  <div class="document-card">
    <p class="document-topic">BRAKE COMPONENTS</p>

LINK IN info.html:
---
<script src="brake-system.js"></script>

================================================================================
QUICK CHECKLIST
================================================================================

When adding a new parent-child:

□ Choose a unique parent name and emoji
□ Create a nav-group in sidebar with parent-item
□ Add child-items with onclick="showContent('unique-id')"
□ Make sure each child has a UNIQUE ID
□ Add matching content-section divs with matching IDs
□ Optional: Create .js file for external content
□ Optional: Link the .js file in script tags

COMMON MISTAKES TO AVOID:

✗ Using spaces in IDs (use hyphens instead: trans-overview NOT trans overview)
✗ Forgetting to match sidebar IDs with content-section IDs
✗ Not wrapping children in <div class="nav-children">
✗ Forgetting style="display:none;" on nav-children
✗ Using same ID for multiple elements

================================================================================

The JavaScript automatically handles:

- Smooth animations
